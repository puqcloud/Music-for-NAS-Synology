# Contributing to Music for NAS Synology

Thank you for your interest in contributing to **Music for NAS Synology**! This is an open-source community project developed for Ubuntu Touch (Lomiri). 

## Bug Reports and Feature Requests
Please use the issue tracker to report bugs or suggest new features. Provide as much context as possible.

## Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Commit your changes with clear messages.
4. Submit a Pull Request against the main branch.
